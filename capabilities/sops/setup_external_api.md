# Setup External API SOP

1. Read the API's required environment variables and auth method.
2. Store only placeholder names in docs or `env.example`.
3. Put real keys in environment variables or a password manager, not in tracked files.
4. Never paste real keys into prompts, logs, or commits.
5. Document how to verify the setup without exposing secrets.
6. If local config is needed, ensure local-only files are ignored by git.
