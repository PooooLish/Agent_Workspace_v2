# Modify Existing Project SOP

1. Inspect the project structure and existing docs.
2. Read the closest `AGENTS.md`, `README.md`, and task notes.
3. Confirm what must change and what must stay stable.
4. Prefer small, localized edits over broad refactors.
5. Back up or duplicate sensitive config files before changing them.
6. Run the minimum useful verification commands.
7. Summarize changed files and any follow-up work.
