# Debug Error SOP

1. Capture the full error message and the exact command that produced it.
2. Reproduce the issue with the smallest possible command or input.
3. Read the nearby code and configuration before editing anything.
4. Form one small hypothesis at a time.
5. Make the minimum fix that addresses the confirmed cause.
6. Re-run the smallest verification command.
7. Record the root cause, changed files, and remaining risks.
