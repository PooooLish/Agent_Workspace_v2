# Python Project Setup

## Purpose

Create or organize a small Python project structure safely and predictably.

## When to use

Use when starting a new Python task, demo, prototype, or utility.

## Procedure

1. Confirm the task scope and target folder.
2. Create a minimal directory structure.
3. Add clear README and task notes.
4. Add starter source and test files if needed.
5. Verify that the layout matches the intended workflow.

## Safety rules

- Do not install packages unless explicitly asked.
- Do not write secrets into files.
- Keep generated files inside the task directory.

## Expected output

A readable Python task structure with basic docs and starter files.
